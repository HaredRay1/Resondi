## 6. Rebuilding, if it is ever needed

The concept note is generated, never hand-edited. To rebuild:

```powershell
cd build\cn2
npm install          # first time only
node build.js
```

Three things about this build:

- **The `docx` version is pinned** to `^9.15.0` in `package.json`. A newer or older version inserts three stray blank paragraphs. If a rebuild produces a dirty diff for no reason, that is why.
- **It reads figures from `..\..\figures\`** relative to the builder, so a new figure must be copied into `figures/` before the build, not after.
- **It writes straight to `final\01-Resondi-Concept-Note.docx`.** The copy in this overlay has already been pointed at this folder's layout; the version used in the chat session wrote to a `deliverables/` folder that does not exist here. That one line at the bottom of `build.js` is the only difference between the two copies.

A rebuild overwrites `final/01-Resondi-Concept-Note.docx` but **not** the PDF beside it. Export a fresh PDF from Word afterwards, or the two will disagree.

If PowerShell refuses to run `npm`:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

`npm.cmd` works as a fallback without changing the policy.

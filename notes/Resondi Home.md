# Resondi

> [!summary] In one line
> An AI-assisted smart stethoscope (ESP32) plus a web app that files lung and heart recordings by chest site,
> analyses them in the browser, and puts every result in front of a practitioner. A screening aid, **never a
> diagnosis**.

> [!warning] Before you quote any number
> Read [[Rules for claims]]. Never "validated", never "diagnoses", never "works on the device", never 71% / 83%.
